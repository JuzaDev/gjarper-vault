# Tassonomia — tag e priorità ammessi

Fonte di verità dei tag del vault. Aggiungere qui un tag **prima** di usarlo nei
task/note. Struttura gerarchica con `/`.

## Tag di dominio
- `#cliente/<nome>` — lavoro per un cliente specifico (es. `#cliente/acme`).
- `#rnd` — ricerca e sviluppo, prototipi, studio.
- `#famiglia` — sfera familiare; sottotag es. `#famiglia/salute`, `#famiglia/scuola`.
- `#burocrazia` — pratiche, scadenze, documenti (SPID, assicurazioni, ...).
- `#casa` — manutenzione, acquisti, gestione domestica.
- `#personale` — tutto il resto della sfera personale.
- `#da-smistare` — marcatore temporaneo per capture non ancora classificate.

## Priorità (emoji Obsidian Tasks)
- `⏫` alta
- `🔼` media
- `🔽` bassa
- (nessuna) = normale

## Date
- `📅 YYYY-MM-DD` — scadenza (due). È ciò su cui filtra `agenda --scadute/--settimana`.
- `⏳ YYYY-MM-DD` — pianificato (scheduled): quando intendo iniziare.

## Convenzioni
- Un task = una riga `- [ ]`. Completato → `- [x]` (o spostato in `30_tasks/archivio/`).
- I tag vanno in coda alla riga del task.
- Niente tag non elencati qui: se serve, prima aggiornare questo file.
