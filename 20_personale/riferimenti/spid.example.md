# SPID (esempio di manifest — sostituire con i dati reali)

- **Cosa esiste:** credenziali SPID livello 2 (username + password + OTP app).
- **Dove si trova:** voce "SPID" nel password manager. Codici di backup in
  `private/identita/spid/` (zona non accessibile all'assistente).
- **Scadenza / data rilevante:** password da rinnovare periodicamente — vedi task
  in `30_tasks/personale.md` con `📅`.
- **Procedura (passi pubblici):** login dal portale del provider; per il rinnovo
  password seguire "recupera credenziali" → OTP sull'app.
- **Note:** provider = <nome provider SPID>. Nessun codice riportato qui.
